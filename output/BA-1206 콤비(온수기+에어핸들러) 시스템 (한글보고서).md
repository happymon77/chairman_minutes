## 00. 한눈에 보기

**탱크리스(순간식) 가스 온수기 1대**로 급탕(DHW)과 난방을 겸하는 **콤비네이션 시스템**의 설계·시공·정비 실무 지침.
건물 단열이 좋아져 난방부하가 낮아질수록, 같은 온수기로 급탕+난방을 처리하는 것이 **초기비용·공간 절감** 면에서 매력적.
NYSERDA·CEE·NRCan 현장 실측과 업계 전문가회의를 근거로, **"무엇이 성능·정비·수용성을 좌우하는가"**를 정리한 것이 핵심.

> **원문의 한 줄 결론**: 콤비는 매력적이지만, ①저유량·단속인출 시 급탕온도 불안정 ②고환수온에 의한 콘덴싱 상실 ③스트레이너 막힘·스케일 정비부담을 반드시 선(先)설계로 잡아야 한다. **→ 해법의 중심은 "작고 잘 단열된 소형 저탕(버퍼)탱크"**.

| 지표 | 값 | 비고 |
|------|-----|------|
| 적정 토출 공기온도 | **100–115°F** (≈38–46°C) | 100°F 미만 = "찬바람" 불만 |
| 콘덴싱 효율(탱크리스) | 환수 **130°F 87% → 80°F 94%** | Magande 2011 |
| 총 열원효율(가스+전기, CEE) | 환수 **120°F 82% → 80°F 91%** | 코일 클수록 저환수 유리 |
| 콘덴싱 유지 환수온 상한 | **≤ 120°F** (≈49°C) | 초과 시 비응축 |
| 잘 작동한 난방부하 상한 | **≈ 35 kBtu/h 미만** | 대부분 고성능 주택이 해당 |
| 설치비(현장) | **$3,500(NYSERDA) ~ $6,000–10,000(CEE)** | 보일러+간접식 대비 절반 이하 사례 |

## 01. 시스템 구성과 작동 원리

**콘덴싱 탱크리스 온수기 + 덕트형 하이드로닉 에어핸들러(수-공기 코일)** 조합이 표준.

**주요 구성품** (원문 Figure 2 계통, 저탕탱크 포함형)
- **탱크리스 온수기** (예: Rinnai RC80HPi 콘덴싱) — 급탕 + 난방루프 열원.
- **하이드로닉 에어핸들러** (예: Rinnai 37AHB045) — 온수 코일이 공기를 데워 기존 덕트로 분배.
- **순환펌프**(Taco 009 등) + **온도조절 믹싱밸브(MMV)** — 급탕 화상방지(120°F).
- **소형 저탕/버퍼탱크**(6–12갤런, 전기, 잘 단열) — *본 가이드의 핵심 권장품*.
- **사전 스트레이너(pre-strainer)** + (선택) 전자식 수질컨디셔너 — 정비주기 관리.

**작동 흐름**
> 온수기 더운물 → 수-공기 코일 → 송풍팬이 데운 공기를 덕트로 순환.
> 급탕 요청 시 **DHW 우선제어**로 난방루프 정지(저탕 없는 시스템에선 필수).

**저탕탱크 유무의 결정적 차이**(현장 실측)
- **탱크 없음**: 저유량(≈0.7 gpm) 인출·잦은 on/off에서 급탕온도 **104°F 미만**으로 자주 떨어짐, 냉수대기 ~1분, 온수기 **점화 사이클 10배**.
- **탱크 있음**: 급탕온도 기대범위 충족, 대기시간 절반, 사이클 1/10 → **거주자 만족**.

## 02. 핵심 기술 사양 (Reference values)

| 항목 | 값 | 비고 |
|------|-----|------|
| 콘덴싱 유지 환수온 | ≤ 120°F (≈49°C) | 초과 시 비응축 |
| 토출 공기온도 목표 | 100–115°F | 105°F↑ 권장, 100°F↓ 찬바람 |
| 온수기 셋포인트 "스위트스팟" | **140°F** (Rinnai) | 믹싱밸브로 급탕 120°F 강하 |
| 급탕 안티스캘드 | ≥ 104°F 유지 / 믹싱 120°F | 화상방지 믹싱밸브 필수 |
| 저유량 점화 임계 | **0.4 gpm** (과거 0.7) | 점화 후 **0.26 gpm**까지 유지 |
| 최소 연소량(모듈레이션 하한) | 15 kBtu/h(분할버너) / 19 kBtu/h(풀온오프) | 하한 클수록 저부하 점화난 |
| 라디안트(바닥) 난방수온 | 98–120°F | 저온·장사이클, DHW 우선제어 불필요 |
| 플래시히팅 가열온도 | 150–185°F | 스케일·스트레이너막힘↑ (Navien은 미사용) |
| 스트레이너 메시 | Rinnai 238µm / Bosch 300µm / BSC 사전스트레이너 200µm | 사전스트레이너로 연1회 정비화 |
| 레지오넬라 위험 온도대 | 69–122°F | 정체수 주의(§6) |
| 소형 저탕탱크 추가비 | ≈ $200(탱크) + $300–400(펌프) | 6–12갤런 전기식 |

## 03. 설계 성공 요건 (Critical Takeaways)

- ✅ **쾌적**: 급탕은 **104°F 이상**, 토출 공기는 **105°F 이상** 유지 → 통상 온수를 **140°F로 가열 + 급탕측 믹싱밸브**. 대형 수-공기 코일을 쓰면 낮은 출탕온도로도 가능하나 장비비↑.
- ✅ **콘덴싱**: 난방 **환수온 120°F 미만** 유지. 펌프유량 제어로 저환수 유도(단, 유량↓ = 토출공기↓ 트레이드오프).
- ✅ **저탕탱크(능동 재가열)**: 안정적 급탕·난방의 **필수품**. 탱크·배관 **철저 단열**(단열 부실 시 50갤런 저탕식만큼 열손실).
- ✅ **정비**: 대형 사전스트레이너로 온수기 유입 스트레이너 청소주기를 **최대 연1회**로. **마그네슘 anode > 알루미늄**(알루미늄은 붕괴물이 스트레이너 막음). 아연도금 피팅은 **플라스틱 라이닝**.
- ✅ **위생**: 급탕과 물을 공유하므로 비수기 **펌프 순환제어**로 정체수 제거(§6).
- ✅ **리트로핏**: 가능하면 온수기까지 **새 급수관** 신설(구관 스케일 이탈 방지).

**콤비가 잘 맞는 집** = 고성능 단열 + 실내 덕트(단열·기밀). 이래야 낮은 토출온도에서 쾌적, 급탕·난방 충돌 최소.
**새 시공(신축)이 최적** — 배관·덕트 사이징을 처음부터 제대로. 리트로핏은 가스관 용량·배기·구관 스케일이 걸림.

## 04. 비용·성능 트레이드오프

**설치비 실측 사례**
- **NYSERDA(뉴욕 유티카)** 딥에너지 리트로핏: 2세대 주택 동일 2시스템, **$3,500/대** — 보일러 교체 대비 절반 이하. 콘덴싱 온수기(EF=0.93) 단품 ~$1,000(EF=0.62 파워벤트의 2배). 급탕 절감 **~$150/yr, 회수 3–4년**. 장비비 절감분을 단열에 재투자 시 냉난방 추가 ~$200/yr 절감.
- **CEE**: 2개 시공사·4개 시스템 **$6,000–10,000/대**.

**초기비용 비교(원문 Table 1, 콘덴싱 TWH 기 보유 가정)**

| 구성 | 비용 | 콘덴싱 퍼니스 대비 |
|------|-----:|------|
| 95% 콘덴싱 퍼니스 | $1,891 | 기준 |
| 콤비 **버퍼탱크 有** | $2,238 | **+$350** |
| 콤비 **버퍼탱크 無** | $1,498 | **−$400** |

> **한랭지 원칙(NRCan/Thomas 2011)**: 콤비가 "콘덴싱 퍼니스 + EF 0.62 온수기"와 대등/우위가 되려면 **반드시 콘덴싱 온수기**를 써야 함.
> **경쟁품**: A.O. Smith Vertex 100 kBtu/h(콘덴싱·직배기·50갤런) = 콤비(TWH+소형저탕)의 대표 경쟁 제품.

**세이빙 테이크백 주의**: 탱크리스의 "무제한 온수" 인식으로 사용량이 늘거나, 온도 불안정 시 유량↑·장시간 사용으로 절감이 상쇄될 수 있음.

## 05. 시스템 설계 전략 (Design Strategies)

- **DHW 우선제어**: 저탕 없는 TWH+에어핸들러는 필수(토출공기 100°F 미만 방지). 일부는 루프 유량 <1 gpm 감지 시 난방펌프 정지.
- **믹싱밸브 + 소형 버퍼볼륨**: 온수기 140°F + 믹싱 120°F + 인라인 버퍼(1.5인치×12인치, ≈1.5컵)로 "냉수 샌드위치"(샤워 중 난방 on/off 시 ±4–6°F 요동) 제거.
- **역류/열사이펀 방지**: 순환기 일체형 체크밸브에 이물 퇴적 → 냉방 중 열사이펀으로 난방코일에 온수 유입(에너지 낭비). **스프링식 체크밸브·솔레노이드**로 차단(1990~2000년대 사례 교훈).
- **라디안트 바닥난방**엔 콤비가 이상적 — 저온수(98–120°F)·장사이클·단순제어, DHW 우선제어 불필요.
- **배기**: 콘덴싱은 직배기(2관 밀폐연소). 배기 재순환 험(humming) 발생 시 **한랭지킷(long-nose snout)**으로 급·배기 이격.

## 06. 보건·안전 · 내구성

**정비 리스크(원문이 가장 강조)**
- **스트레이너 막힘** = BSC가 실제로 겪은 유일한 심각 문제. 폐루프 순환이 anode 붕괴물·미네랄 침전을 온수기 유입 스트레이너로 몰아넣음. 사전스트레이너 없으면 청소주기 **수일~수개월**, 대형 사전스트레이너(200µm SS, ~$150)로 **연1회**화.
- **플래시히팅 기종**(물 일부를 150–185°F로 과열)일수록 탄산칼슘 침전↑. **Navien은 플래시 미사용**(스테인리스 열교환기, 필요분만 가열) → 정비주기에 유리.
- **스케일·부식**: 물을 뜨겁게 할수록 스케일·갈바닉부식↑. 전자식 수질컨디셔너가 기존 스케일 제거·신규억제에 유효(Rinnai 비콘덴싱기 4년 무결함 사례). 과연수(over-softening)는 보호막 제거로 오히려 동관 침식.

**레지오넬라(정체수)**
- 비수기 난방순환펌프 장기 정지 시 **69–122°F** 루프에서 증식 위험. **주 1회·1분 순환**(루프 1회전)으로 물 교체. 펌프 사이클 타이머 사용.

**안전**: 120°F 초과 제어 급탕엔 **스캘드 방지 믹싱밸브 필수**.

## 07. 평가 표준 · 장벽 (Rating & Barriers)

**북미 2대 시험법**
- **ASHRAE 124-2007** (가스·오일·전기 / 강제급기·하이드로닉) → CAE(Combined Annual Efficiency). **결함**: 부품 개별시험만 허용(전체 시스템 실성능 평가 불가), 최대/최소 입력만 시험해 모듈레이션 제어를 꺼야 함, 비현실적 규정온도.
- **CSA P.9-2011**(개발중, 가스·오일 / 강제급기) → TPF·CSHE·WHPF·OHR. **개선점**: 실사용 셋포인트·제어 반영, **부분부하 15%·40% + 최대입력** 가중 시험.

**미개화 장벽(Gaps & Barriers)** — *PNNL 자료와 정확히 일치*
- **공인 표준·검증 가이드 부재** → 대부분 소규모 독립 시공사의 시행착오식 설계.
- 최적화엔 **종합 제어전략**(가변속 펌프·팬 + 모듈 가스밸브 + 다중 온도·유량센서로 환수온·토출공기·급탕온 협조제어)이 필요.
- **공장공급 완제품 세트** 부재로 다공급자 부품 충돌 → 통합 총시스템 필요.

## 08. 정리 · 시사점

- **가치 제안**: 탱크리스 1대로 급탕+난방, 공간절약, 보일러+간접식 대비 절반 이하 설치비 사례. 단, **콘덴싱 온수기 + 소형 저탕탱크**가 성패의 축.
- **핵심 리스크 3종**: ①저유량·단속인출 급탕 불안정(→저탕탱크) ②고환수온 콘덴싱 상실(→환수 120°F 미만·대형코일) ③스트레이너/스케일 정비(→사전스트레이너·마그네슘 anode·플라스틱 라이닝).
- **제도 급소**: ASHRAE 124의 부품별 시험 한계 → **CSA P.9의 부분부하 시험**이 실성능·리베이트의 관문(캐나다).
- **국내(대성쎌틱·RING TWIN) 관점**:
  - BA-1206은 **콤비(1대 겸용)** 가이드로, RING TWIN(**2대 분리**)과 구조는 다르나 **물리·정비·인증 급소는 그대로 적용**됨.
  - 직접 활용점 → (a) **토출공기 105°F·환수 120°F** 기준을 RING 벤치 합격선에 반영, (b) **저유량 0.4/0.26 gpm 임계**·최소연소량(15–19 kBtu/h) 단락사이클을 성능시험 항목화, (c) **사전스트레이너·마그네슘 anode·플라스틱 라이닝**을 표준 BOM에, (d) **주1회 순환**을 레지오넬라 대책으로(RING 요약본 히팅박스 폐루프면 부담↓), (e) **CSA P.9 부분부하(15%/40%) 시험**을 캐나다 진입·리베이트 근거로(요약본 §8과 정합).
  - RING TWIN의 차별점(2대 상호백업)은 BA-1206이 지적한 **"단일 온수기 고장 시 급탕·난방 동시정지"** 리스크를 정면 해소 → 본 원문이 그 약점을 **DOE 문헌으로 공인**해 주는 근거.
