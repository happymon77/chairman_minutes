이번 세션 작업을 **두 곳**에 기록하라. 상세는 `handoff/`, 요약은 `작업현황.md`.

## 참고 컨텍스트
- 회장님 클로바노트 원본과 회의자료를 맞춤법·오인식 교정 후 정식 회의록 및 주요 지시사항으로 정리하는 프로젝트.
- 회장님 표현과 논지는 최대한 보존하고, 확실하지 않은 인명·수치·기술용어는 추정 확정하지 않는다.
- git 조회는 하지 않는다. 결과물과 변경 여부는 실시간 로그, 대화 기억 및 실제 파일로 확인한다.
- 사용자 추가 메모: $ARGUMENTS

## 0. 사실 수집 먼저 (수집 없이 작성 시작 금지)
1. 오늘 `handoff/{오늘 YYYY-MM-DD}.md`의 **`## 실시간 로그`**를 읽어라. 작업 중 append된 1차 자료를 상세 정리의 뼈대로 사용한다.
2. `작업현황.md` 최상단 `▶ 현재 상태` 블록과 `진행 타임라인` 최신 줄을 읽어라.
3. 오늘 만들거나 고친 산출물 경로를 Glob으로 확인한다. 실제 파일 경로가 정본이다.
4. 실시간 로그가 없거나 비어 있으면 대화 기억으로 쓰되 `실시간 로그 없음`이라고 밝힌다.

## 1. handoff/{오늘 YYYY-MM-DD}.md = 그날의 상세
실시간 로그는 **그대로 두고**, 그 아래 `## 정리` 섹션을 채우거나 갱신한다. 파일이 없으면 생성한다.

- **결과물**: `파일 경로 + 한 줄 설명 + 상태(완료/진행 중)`. 원본 파일이 정본이다.
- **시도 → 결과**: 무엇을 어떻게 했고 결과가 무엇이었는지 적는다.
- **실패·기각(이유)**: 버린 접근과 이유를 반드시 적는다. 없으면 `없음`으로 쓴다.
- **수정 사유**: 문장·수치·구조·형식을 바꿨다면 근거를 적는다.
- **다음 단계 / 블로커**와 **열린 질문**을 적는다.
- 발언 정리 작업에서는 회장님 직접 발언, 참석자 의견, 문맥상 보완 내용을 구분하여 기록한다.

## 2. 작업현황.md = 간단 요약 (2층을 섞지 마라)
### (A) 최상단 `▶ 현재 상태` 블록 = 매번 덮어쓰기
아래 스키마 6섹션을 모두 채운다. 해당 내용이 없으면 `없음`으로 쓴다. 상세 근거는 `handoff/{오늘}.md 참조`로 가리킨다.

### (B) `진행 타임라인` = 보존·append
- 상단 `> **최종 갱신: …**` 날짜를 오늘로 고친다.
- `진행 타임라인` 맨 위에 오늘 후속 번호 한 줄을 추가한다.
- 형식: `- **후속N (YYYY-MM-DD)** — 1~2줄 요약. → \`handoff/{오늘}.md\``
- 기존 타임라인은 삭제하거나 수정하지 않는다.
- 기존 `작업현황.md`의 오래된 `진행 로그`가 있으면 과거 기록으로 그대로 보존한다.

## 3. 최상단 블록 스키마 — 이 형식 그대로
```markdown
## ▶ 현재 상태 (핸드오프 스냅샷 · 매 세션 덮어쓰기)
> 다음 세션은 이 블록부터 읽는다. 과거 요약은 아래 "진행 타임라인", 상세는 handoff/ 날짜별 파일.
**갱신: {YYYY-MM-DD HH:MM} · 후속{N}**

**1. 한 줄 국면** — 지금 무슨 단계인지 1~2문장.
**2. 다음 첫 액션** — 다음 세션이 바로 실행할 작업. 대상 파일과 확인·수정 범위를 구체적으로 적는다.
**3. 진행 중 (미완결)** — 무엇을 어디까지 했고 무엇이 막혔는지, 재현 가능한 파일·명령과 함께 적는다.
**4. 이번 세션 확정** — 결론과 근거(수치·발언자·페이지·파일), 기각한 대안과 사유를 적는다.
**5. 함정·건드리면 안 되는 것** — 원본 보존, 발언자 혼합, 추정 교정, 정본 파일 등 현재 작업의 위험을 적는다.
**6. 열린 질문 / 대기** — 사용자 확인, 참석자 확인, 원본 녹취 또는 외부 회신 대기를 적는다.
```

## 4. 자가검증
- [ ] `작업현황.md`의 최상단 블록만 읽고 다음 세션이 `다음 첫 액션`을 바로 실행할 수 있는가?
- [ ] `handoff` 상세에 실패·기각·수정 사유가 적혀 있는가?
- [ ] 모든 결론에 발언자·페이지·수치·파일 등 확인 가능한 근거가 붙어 있는가?
- [ ] 회장님 직접 발언과 참석자 의견, 편집자의 기술적 보완이 명확하게 구분되어 있는가?
- [ ] `계속 진행`, `마무리`, `정리` 같은 추상적인 다음 단계가 남아 있지 않은가?

마치면 handoff 파일 경로와 작업현황 갱신 내용을 3줄 이내로 보고하라.
