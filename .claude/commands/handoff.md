이번 세션에서 한 작업을 바탕으로 프로젝트 루트의 `작업현황.md`를 갱신하라.

## 참고 컨텍스트 (git 미사용 프로젝트면 무시)
- 현재 브랜치: !`git branch --show-current 2>/dev/null || echo "(git 미사용)"`
- 최근 커밋: !`git log --oneline -5 2>/dev/null || echo "(git 미사용)"`
- 변경 파일: !`git status --short 2>/dev/null || echo "(git 미사용)"`
- 사용자 추가 메모: $ARGUMENTS

## 갱신 규칙
1. `작업현황.md`가 없으면 아래 구조로 새로 만든다.
2. 상단 4개 섹션(현재 상태 / 결과물 / 과정·결정 / 다음 단계)은 **최신 내용으로 덮어쓴다.**
3. 맨 아래 "진행 로그"에는 오늘 날짜(YYYY-MM-DD) 항목을 **추가만** 한다. 기존 로그는 절대 삭제하지 않는다.
4. 내용은 사실 진술로 쓴다. (명령문 X)

## 각 섹션에 반드시 담을 것
- **결과물**: 요약하지 말고 `파일 경로 + 한 줄 설명 + 상태(완료/진행중)`로 가리켜라. 원본 파일이 진짜 기록이다.
- **과정·결정**: 왜 그렇게 결정했는지, 무엇을 시도했다 버렸는지, 지금 막힌 점/열린 질문은 무엇인지. ← 내일 이걸로 맥락을 복원하므로 가장 중요하다.
- **다음 단계**: 바로 할 일과 블로커를 체크박스로.

## 참고 구조
```
# 작업 현황 (STATE)
## 1. 현재 상태 (한 줄 요약)
## 2. 결과물 (Deliverables)  — 파일 경로 표
## 3. 과정 · 결정 (Process)
## 4. 다음 단계 (Next)  — 체크박스
---
## 진행 로그 (append-only)
### YYYY-MM-DD
- ...
```

갱신을 마치면, 무엇을 덮어썼고 로그에 무엇을 추가했는지 3줄 이내로 요약해서 보고하라.
